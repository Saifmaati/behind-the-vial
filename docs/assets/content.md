# Content module: third-party assets

None. The content module ships no third-party assets.

- Icons in `js/ui/icons.js` (phone, clock, alert, target, arrows, flask, vial and so on) and the small front-view body glyphs for the site picker were drawn for this project as inline SVG paths. No icon set was copied.
- The charts in `js/ui/charts.js` are hand-written SVG. No charting library is used.
- Fonts come from the shared tokens (`css/tokens.css`, foundation). The content CSS adds no font files. Its monospace stack names system fonts only.
- The sample data files contain placeholder text only. Their sample source URLs point to `example.org`, which is reserved for documentation.
