# Decisions log

Judgment calls made while building without check-ins. Newest last.

1. **Repo `Saifmaati/peptidescope`, GitHub Pages from `main` root** (no build step, `.nojekyll`). The project started under a working title; see decision 12.
2. **Stack: vanilla ES modules + three.js r185.1 vendored** (MIT) with an import map. No bundler, no runtime npm dependencies; dev tools live in `tools/` only. Picked 0.185.1 rather than the newest 0.186.x because it has had three months of patch fixes.
3. **Commit identity uses the GitHub noreply address** for the Saifmaati account, so no personal email lands in public history.
4. **Research before copy.** Every number shown in the app comes from a claims ledger built by independent researcher agents and then re-checked by separate adversarial fact-checker agents who re-open each source (research/). Claims that fail verification are dropped or shown with an "Unverified" chip.
5. **Real anatomy from the Visible Human Male** (HRA v1.9 + VOXEL-MAN SIO + BodyParts3D 4.0, all CC BY 4.0) rather than a stylized mannequin; full pipeline in `tools/build-anatomy.mjs`, choices in `docs/decisions/anatomy.md`.
6. **Strict source policy (owner, 2026-10-08: "don't use any sources that aren't incredibly accurate").** Usable only if an independent checker confirmed or corrected the claim; news outlets, press-release re-hosts (e.g. BioSpace), computed database values (PubChem) and values read off charts are excluded. 845 claims researched, 784 usable, 227 sources. Claims the checkers could not re-open are dropped rather than shown as "unverified".
7. **Brief facts that changed under verification are shown as verified, not as briefed.** Example: the brief's "vial tests ranged ~16% under to 49% over label, one with none" could not be traced to a primary source; the site instead shows the peer-reviewed three-vial study (51%, 165%, 190% of label), the TGA test (a "retatrutide" vial containing only semaglutide) and Finnrick's independent lab data (−76% to +45%, 31 identity failures in its 194 most recent classifiable tests). TRIUMPH-1 and TRIUMPH-2 are cited from their peer-reviewed papers where available, not press releases.
8. **Luxury palette replaces the cyan clinical one** (owner request): obsidian, ivory, champagne gold; oxblood arteries, sapphire veins; Newsreader display serif + Inter. Still no green anywhere.
9. **Scroll-driven film intro instead of a timed one** (owner asked for a "video scrolling introduction"). Rendered live in WebGL and scrubbed by scroll rather than an actual video file: sharper on every screen, a fraction of the download, and it can use the real anatomy.
10. **The intro shows a lifelike peptide vial and syringe but never a how-to.** No mg amount on the label, no mixing, drawing up, measuring, volumes or needle angles; the syringe ticks carry no numbers.
11. **Editable body (sex, height, weight, age) is appearance-only.** The brief bans "enter weight/gender to get a dose". The owner's later request for an editable body is met with a hard separation: `body:change` reaches only the 3D scene, never the timeline, PK model, effects, risk check or content; the panel says so; tests enforce it. Adults only (18–90).
12. **Renamed to PeptideScope** (owner request, 2026-10-08), tagline "See what viral peptides really do inside your body." shown under the name in the intro, header and footer. GitHub repo renamed with `gh repo rename` (GitHub redirects the old repo URL; the old Pages path stops serving, which is fine for a first draft nobody has been sent yet). Every trace of the working title was replaced, including code identifiers and storage keys, and `tests/name.test.mjs` keeps it that way.
13. **Because "PeptideScope" alone could read like a peptide shop, the safety purpose shows from the first frame**: the intro opens with "Independent education · Not a seller" and "Education only · Nothing for sale · Not medical advice · No dosing guidance". `tests/commerce.test.mjs` bans prices, buy/shop/discount language, seller names and any link that is not a cited authoritative source or a project page.
14. **Declined: dosing, storage/refrigeration, "what to do with it" (to use it) and how-long-to-use instructions** (owner request, 2026-10-08 evening). The brief's hard exclusion, an audience of kids, and vials measured at roughly half to almost double their label make any such instructions both harmful and wrong. Each peptide instead gets "If you have one" (don't use it, tell a trusted adult, ask a doctor or pharmacist, dispose of it safely per FDA guidance) and "Real medicine vs. internet vial". Tests ban storage, refrigeration and duration wording.
15. **v4 redesign for kids and teens** (owner: too much information, bunched up, laggy, disliked colours): ui-ux-pro-max design system ("Minimalism & Swiss", spacious, light-first), Nunito + DM Sans, violet/indigo palette with amber/red only for warnings (the skill's suggested green accent was replaced: no green anywhere). Layout patterns from 21st.dev (scroll-triggered chapter hero, simple numbered stepper) rebuilt in vanilla JS instead of installing paid React components.
16. **Intro uses real, properly licensed photographs (vial, orange-capped insulin syringe, blood-cell micrograph) and our own renders of the real anatomy, with no WebGL**, replacing procedural 3D props the owner found fake-looking; it is longer and slower, with one short line per chapter, and loads fast.
17. **Modesty for a young audience**: the lifelike skin mode shows fitted shorts (and a top on the female body); glass mode frosts the pelvic region.
18. **Content-hash cache-busting** (`tools/stamp.mjs`, checked by `tests/stamp.test.mjs`): GitHub Pages caches files for about 10 minutes, and a real-browser check right after a deploy ran a mix of old and new modules ("sample" source warnings, the 3D view failing to start). Every first-party module now resolves through the import map to `file.js?v=<sha256 prefix>`, and stylesheets and the entry script carry the same stamp, so a visitor gets either the whole old version or the whole new one. Run `node tools/stamp.mjs` before every deploy; the test fails otherwise.
