# PeptideScope

**Live site: https://saifmaati.github.io/peptidescope/**

*See what viral peptides really do inside your body.*

An education-only visual explainer of what happens inside the body after someone injects a peptide that is going viral on social media, starting with retatrutide. Every factual claim is cited. It is not medical advice and it never gives dosing guidance.

> Status: first draft in progress (2026-10-07). This README is updated as parts land.
